# PinKuis H5P Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pemilik konten yang login bisa mengunggah file `.h5p`, menyetel timer, publish, dan membagikan PIN 6 angka; peserta tanpa akun mengerjakan konten itu lewat PIN dan melihat posisinya di papan peringkat, sementara pemilik melihat skor seluruh peserta.

**Architecture:** Satu aplikasi Next.js App Router. Berkas `.h5p` diunggah dari browser langsung ke Vercel Blob, diekstrak oleh satu route handler, lalu dilayani kembali ke pemutar lewat route proxy satu-origin yang memeriksa kewenangan. Skor datang dari event xAPI yang dipancarkan konten H5P, dicatat progresif ke Postgres, dan batas waktu dihitung di server.

**Tech Stack:** Next.js 16.4.2 (App Router), React 19.3, TypeScript strict, Tailwind v4 (CSS-first), Drizzle ORM + Postgres (Neon), Vercel Blob, `h5p-standalone` v3, `fflate`, `bcryptjs`, `qrcode`, Vitest + Testing Library.

**Spec:** [`docs/superpowers/specs/2026-10-22-pinkuis-h5p-design.md`](../specs/2026-10-22-pinkuis-h5p-design.md) — rencana ini berargumen dari spec itu; pelaksana membaca keduanya.

## Global Constraints

- **Next.js 16, bukan 15.** `middleware.ts` tidak ada lagi — berkasnya bernama `proxy.ts` di root proyek, mengekspor `proxy(request)` (named atau default) plus `config.matcher`. Jangan buat `middleware.ts`.
- **`cacheComponents: true` sudah menyala** di `next.config.ts`. Membaca `cookies()` di luar batas `<Suspense>` adalah error saat build. Semua pembacaan sesi login lewat satu fungsi ber-`'use cache: private'`; komponen yang memakainya duduk di balik `<Suspense>`. Fungsi ber-`'use cache'` biasa **tidak boleh** memanggil `cookies()`.
- Route handler dinamis memakai `RouteContext<'/path/[param]'>` dan `await ctx.params` — `params` adalah Promise.
- `proxy.ts` hanya untuk pengalihan optimistis (ada/tidak ada cookie). Otorisasi sebenarnya diperiksa ulang di setiap route handler dan server action, dekat dengan data.
- Path alias `@/*` → root proyek. TypeScript `strict`. Tailwind v4 dikonfigurasi di CSS (`@theme`), bukan `tailwind.config.js`.
- Batas ukuran unggahan `.h5p`: **20 MB**. Body request route handler di Vercel ~4,5 MB, jadi berkas **tidak pernah** melewati server aplikasi — unggahan langsung browser → Blob.
- PIN: **6 digit desimal**, acak kriptografis, unik di antara sesi yang belum `closed`. Disimpan tanpa spasi, ditampilkan `482 913`.
- bcrypt cost **12**. Cookie sesi login: `httpOnly`, `sameSite=lax`, `secure` di produksi, umur **30 hari**.
- Nama peserta maksimum **40 karakter**; keunikan per sesi **wajib** (tidak ada opsi mematikannya).
- Peringkat: `score_raw` menurun, lalu durasi menaik. Percobaan belum selesai tidak diberi posisi.
- Polling dasbor: **10 detik**. Skala sasaran 100 peserta serentak — sambungan Postgres dari fungsi wajib lewat connection string pooled.
- Tipe konten yang wajib terbukti benar pembacaan skornya: `H5P.QuestionSet`, `H5P.InteractiveVideo`, `H5P.CoursePresentation`.
- Antarmuka berbahasa Indonesia, `<html lang="id">`. Token warna dan font persis seperti §8 spec.
- Setiap pesan commit diakhiri baris `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.

## Review Focus

Lima kelas masukan yang disiratkan spec tapi tidak akan teruji sendiri. Tes untuk masing-masing sudah ditambahkan ke task yang memiliki kodenya.

1. **Dua peserta mengirim nama yang sama nyaris bersamaan.** Indeks unik akan menolak yang kedua; yang harus dilihat peserta adalah pesan "nama sudah dipakai", bukan 500. → Task 11.
2. **Paket `.h5p` cacat:** bukan ZIP, tanpa `h5p.json`, atau berisi entri dengan `../` di path. Yang terakhir bisa menulis berkas ke luar prefiksnya. → Task 6.
3. **Statement xAPI tanpa `result.score`, atau dengan `max: 0`.** Persen tidak boleh `NaN` atau `Infinity`, dan statement tanpa skor tidak boleh menimpa skor yang sudah ada. → Task 12.
4. **Peserta mengirim progres setelah tenggat terlampaui.** Permintaan itu harus menutup percobaan dengan status `timeout` dan skor yang sudah ada, bukan menambah skor baru. → Task 12.
5. **PIN yang dikirim mengandung spasi atau bukan angka, atau milik sesi `draft`/`closed`/di luar jendela akses.** Tiap keadaan punya pesan yang menyebut sebabnya. → Task 11.
